# Ritu Mahajan Agency Chandigarh — Website Project

A bespoke, high-converting website built for **Ritu Mahajan Agency Chandigarh**, taking architectural and structural reference from [Averiqo](https://www.averiqo.co.in/) while introducing a completely distinct, vibrant luxury design and color scheme.

---

## 🎨 Visual Identity & Color Distinction from Averiqo

| Feature | Reference Website (Averiqo) | Ritu Mahajan Agency Chandigarh |
| :--- | :--- | :--- |
| **Aesthetic Direction** | Monotone dark navy/slate (`#111a2b`), stark and restrained | **Vibrant Editorial Luxury & Tech Precision** |
| **Primary Palette** | Dark Slate & Navy | **Royal Velvet Indigo (`#0b132b`, `#1c2541`) & Deep Sapphire** |
| **Accent Colors** | Muted cyan & muted greys | **Vibrant Rose Gold (`#e11d48`), Electric Indigo (`#4f46e5`), Warm Amber (`#f59e0b`), Emerald (`#10b981`)** |
| **Theme Support** | Dark only | **Dual Light & Dark Mode** with instant toggle and memory persistence |
| **Visual Texture** | Flat dark containers with thin 1px borders | **Glassmorphism cards, ambient light glows, soft shadows, rounded 3xl cards** |
| **Typography** | Generic sans-serif | **Outfit** (high-impact editorial headings) + **Plus Jakarta Sans** (crisp UI body copy) |

## 💻 Tech Stack

- **HTML5 & Vanilla JavaScript**: Zero dependencies, sub-second load speed, lightweight, and deployable on any hosting provider (Vercel, Netlify, Cloudflare Pages, GitHub Pages, or Apache/Nginx).
- **Tailwind CSS (via CDN)**: Custom extended color palette, gradients, and utility classes.
- **Lucide Icons**: Crisp, modern SVG icons.
- **Google Fonts**: `Plus Jakarta Sans` & `Outfit`.
